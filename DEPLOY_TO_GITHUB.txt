HITMS — FINAL CLOUDFLARE-READY PACKAGE

IMPORTANT:
This ZIP contains the complete HITMS foundation project. Do NOT upload the ZIP file itself into GitHub expecting GitHub to unpack it.

1. Extract this ZIP on your PC.
2. Open the extracted HITMS folder.
3. In GitHub open: ansab-maqsood/hitms, branch main.
4. Choose Add file -> Upload files.
5. Upload ALL files and folders inside this HITMS folder to the repository ROOT.
   The repository root must directly contain:
   package.json
   wrangler.toml
   vite.config.ts
   index.html
   src/
   public/
   supabase/
   tsconfig.json
   tsconfig.app.json
   tsconfig.worker.json
   .env.example
   README.md
6. Make sure src/ contains ALL of these:
   App.tsx
   main.tsx
   styles.css
   vite-env.d.ts
   worker.ts
   lib/supabase.ts
7. Commit directly to main.

CLOUDFLARE WORKERS BUILD SETTINGS:
Build command: npm run build
Deploy command: npx wrangler deploy
Root directory: /

The Worker entry point is src/worker.ts and it serves the Vite dist assets through env.ASSETS.
